# BLOOM

واجهة متجر جمال وعناية بالعربية والإنجليزية، بثيمين أسود/ذهبي وأبيض/ذهبي، ومشاهد منتجات شفافة متبدلة وبطاقات متحركة وسلة تفاعلية.

## التشغيل محليًا

يحتاج Node.js 18 أو أحدث. لا توجد حزم مطلوب تثبيتها.

```sh
npm start
```

ثم افتح `http://127.0.0.1:2051/index.html`. يمكن استخدام `node tools/serve.cjs --port=2052` إذا كان المنفذ مشغولًا. لا تفتح HTML مباشرة عبر file:// بسبب ES modules.

## الملفات

- `index.html` و`en.html`: واجهتا العربية والإنجليزية.
- `assets/`: صور الموقع، ومنها خمسة مشاهد شفافة جديدة للواجهة الرئيسية.
- `vendor/`: المكتبات والخطوط المحلية وتراخيصها.
- `docs/MASTER-PROMPT.md`: ماستر برومبت تفصيلي لإنشاء موقع مشابه بموضوع مختلف.
- `docs/HOW-TO-USE-PROMPT-AR.md`: شرح عربي للتخصيص.
- الوحدات تفصل الثيم والحركات والسلة والحساب وتتبع الطلب والتقييمات والشكاوى والسياسات.

## حالة المشروع

هذه **معاينة واجهة وليست متجرًا تجاريًا مفعّلًا**. الأسماء والصور والأسعار تجريبية. SMS وOTP والحسابات والطلبات والمدفوعات والشحن ونشر التقييمات وتذاكر الدعم الرسمية والنشرة البريدية غير مربوطة. أرقام الشكاوى الحالية مراجع محلية تجريبية؛ لا تُرسل الشكوى تلقائيًا. الدفع مخطط له خارج الموقع.

صفحات الخصوصية والكوكيز والأحكام والشروط مسودات لحالة المعاينة وتحتاج بيانات الجهة المشغلة وشروط البيع قبل الإطلاق. لا توجد مفاتيح خدمات أو بيانات عملاء ضمن هذا المستودع.

وجود الملفات على GitHub لا يعني نشر الموقع على استضافة. لم تُفعّل GitHub Pages أو خدمة نشر تلقائي.

## الحقوق

احتُفظ بتراخيص المكتبات والخطوط في `vendor/`. لم يُمنح ترخيص جديد شامل للكود أو الأصول؛ تُراجع الحقوق قبل إعادة التوزيع التجاري.
