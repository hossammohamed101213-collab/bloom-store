# استخدام الماستر برومبت

1. افتح `MASTER-PROMPT.md` وانسخ محتواه بعد تعبئة قسم Project variables.
2. اكتب اسم المشروع والمجال والجمهور والبلد والعملة وأصناف المنتجات أو الخدمات ورقم التواصل الحقيقي.
3. إن لم تتوفر بيانات فعلية، اكتب DEMO بوضوح. إن لم تتوفر قاعدة بيانات أو SMS، اكتب NONE في التكاملات المتاحة.
4. أرفق `project/beauty` مع صور المعاينة كمرجع. لا تجعل النسخة القديمة في `project/index.html` هي مرجع البداية.
5. اطلب من أداة البرمجة تنفيذ الموقع وتشغيله وفحصه في المتصفح، لا الاكتفاء بكتابة تصور.

## مثال: متجر قهوة بدل التجميل

```text
BRAND_NAME: [اسم مشروعك]
SUBJECT / INDUSTRY: Specialty coffee and coffee equipment
MODE: product store
AUDIENCE: Arabic/English-speaking coffee enthusiasts
COUNTRIES / CURRENCY: [الدول والعملة الفعلية]
CONTACT_PHONE / WHATSAPP: [رقمك الصحيح]
CATEGORIES: Coffee beans, brewing tools, cups, grinders, gift sets
CATALOGUE_DATA: Clearly labelled demo listings until real product data is provided
LIVE_INTEGRATIONS_AVAILABLE: NONE
COMPANY_LEGAL_DETAILS: NOT PROVIDED
HOSTING / DOMAIN: LOCAL PREVIEW ONLY
```

وفي نهاية الرسالة اكتب:

> حافظ على توزيع BLOOM، والثيمين الأسود/الذهبي والأبيض/الذهبي، والخطوط الواضحة، وحركة البطاقات، والسلة والواجهة التفاعلية. استبدل صور مستحضرات التجميل بخمسة تكوينات شفافة مخصصة للقهوة. لا تدّع تشغيل OTP أو الطلبات أو الدفع قبل ربطها فعلًا. اعرض لي النتيجة في المتصفح قبل النشر.

## إذا كان الموقع خدمات وليس متجرًا

غيّر MODE إلى services catalogue، وحوّل المنتجات لخدمات والسلة إلى قائمة طلب عرض سعر. لا تضف عملية دفع أو أسعارًا أو وعودًا لم تحددها. تظل بطاقات التفاصيل والتقييمات وخدمة العملاء والحركات صالحة بعد تكييفها.

## نقاط مهمة

- النموذج يولّد تصاميم مماثلة، لكنه لا يضمن نسخة متطابقة دون إرفاق المصدر والصور المرجعية.
- لا ترسل مفاتيح خدمات سرية داخل البرومبت أو ملفات الواجهة.
- لا تعتمد على أرقام شكاوى محلية أو حالات تتبع تجريبية كبيانات حقيقية للعملاء.
- راجع اسم النشاط والصور وبيانات الاتصال والحقوق والسياسات قبل أي نشر تجاري.
